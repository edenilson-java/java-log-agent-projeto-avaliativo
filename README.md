Agente de diagnóstico de logs Java e Spring Boot, com LangGraph, MCP e FastAPI.

O projeto evolui o mini-projeto do módulo, preservando as capacidades já entregues e
acrescentando arquitetura agêntica, integrações, memória, segurança, observabilidade,
QA com IA, DevOps e automação low-code.

## Estado deste commit

Commit inicial de bootstrap do repositório: contém apenas `.gitignore` e este `README.md`.

O código da aplicação, os testes, os exemplos e a documentação entram nas etapas seguintes,
por Pull Requests com destino à branch `develop`. Este arquivo é substituído pela versão
completa — com instalação, execução, arquitetura, cenários de uso e link do vídeo de
demonstração — na etapa de documentação.

## Fluxo de versionamento

`develop` → `feature/*` → `develop` → `main`

As feature branches nascem da `develop`. Os Pull Requests das etapas técnicas têm destino a
`develop`, e a `main` recebe apenas a integração final.
